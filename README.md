#   NorthWay Guide – AI Powered Travel Ecosystem

  Live Website: https://northwayguide.com

---

##  Project Overview

**NorthWay Guide** is a full-stack AI-powered travel and tourism platform designed to simplify and enhance travel experiences in Northern Pakistan.

The system combines **machine learning, generative AI, real-time APIs, and a marketplace ecosystem** to provide intelligent travel solutions including trip planning, weather updates, tourism guidance, and local services.

---

##  Project Objective

To develop a centralized smart travel platform that helps users:

- Plan trips based on budget and preferences
- Get real-time weather and travel updates
- Explore tourist destinations in Northern Pakistan
- Access hotels, transport, and local guides
- Buy/sell local products through a marketplace
- Interact with an AI travel assistant

## Key Features

### AI Trip Planner (Machine Learning Based)
- Built using **Random Forest Regression Model**
- Generates personalized travel itineraries
- Input parameters:
  - Budget
  - Duration
  - Travel preferences
- Outputs:
  - Day-wise trip plan
  - Suggested destinations
  - Estimated costs
  - Transport and hotel suggestions

---

###  AI Chatbot (Gemini API)
- Powered by **Google Gemini AI**
- Acts as a smart travel assistant
- Provides:
  - Travel guidance
  - Destination recommendations
  - Safety and route advice
  - General Q/A support

---

###  Tourist Spots Explorer
